# よくある質問

### 初回起動が macOS にブロックされるのはなぜですか？

アプリは自己署名証明書を使用しており、Developer ID 署名も Apple の公証もありません。「システム設定 → プライバシーとセキュリティ」で「このまま開く」を一度クリックするか、`xattr -d com.apple.quarantine /Applications/Bowerbird.app` を実行してください。

### なぜアクセシビリティの許可が必要ですか？

Return を押したときに、元の App で ⌘V を代わりに押すためです。最初にペーストするときに求められます。許可しなくても使えます。その場合 Return はコピーだけを行い、ペーストは自分で行います。

### 許可したのに Return でペーストされません。

許可は App の署名に結び付いています。スイッチがオンに見えても、古い署名のものである場合があります。「システム設定 → プライバシーとセキュリティ → アクセシビリティ」で Bowerbird を「−」で削除し、「+」で追加し直してください。

### 許可を取り消したのに、App には許可済みと表示されます。

macOS は実行中の App に変更を通知しません。Bowerbird を終了して開き直してください。

### 画面収録やフルディスクアクセスは必要ですか？

不要です。画像はクリップボードから取得し、ファイルはパスだけを保存します。

### インターネットに接続しますか？

しません。テレメトリも、アップデートの確認も、同期もありません。

### データはどこにありますか？

`~/Library/Application Support/Bowerbird/` です。SQLite データベースと画像ファイルで、暗号化はされていません。設定は `defaults` の `app.bowerbird.mac` にあります。

### すべて削除するには？

「設定 → 履歴 → 消去 → すべて」で履歴を消去します。ピン留めした項目には、その下の行に専用の消去ボタンがあります。同じページの「終了時に消去」をオンにすると、終了のたびに自動で消去されます。ピン留めした項目は残ります。痕跡をすべて消すには、App を終了してから次を実行します。

```sh
rm -rf ~/Library/Application\ Support/Bowerbird
defaults delete app.bowerbird.mac
```

### 記録されないものは？

- パスワードマネージャがパスワードとしてマークしたもの。
- 除外リストにある App でコピーしたもの。デフォルトで 1Password、Bitwarden、キーチェーンアクセスが入っています。
- 除外パターンに一致するテキスト。
- 記録を一時停止している間にコピーしたもの。

### 履歴はどのくらい保持されますか？

テキストとファイルは 30 日、画像は 7 日です。「設定 → 履歴」で変更できます。ピン留めした項目は無期限に保持されます。

### スクリーンショットが出てこないのはなぜですか？

macOS はデフォルトでスクリーンショットをデスクトップにファイルとして保存し、クリップボードには入れないため、Bowerbird からは見えません。代わりに ⌃⇧⌘4 を押すとクリップボードにコピーされます。または ⇧⌘5 を押し、「オプション」で「保存先」を「クリップボード」にしてください。

### iPhone や iPad でコピーしたものは記録されますか？

「設定 → 履歴」のオプションがオンなら、テキストと画像は記録されます。ファイルは記録されません。
