# 常见问题

### 第一次打开为什么被系统拦住？

应用使用自签名证书，尚无 Developer ID 签名，也未经过 Apple 公证。到「系统设置 → 隐私与安全性」点「仍要打开」放行一次，或者执行 `xattr -d com.apple.quarantine /Applications/Bowerbird.app`。

### 为什么要辅助功能权限？

按回车时替你在原来的应用里按 ⌘V。第一次粘贴时才申请。不给也能用，回车只复制，自己粘贴。

### 给了权限，但回车粘不出来。

授权绑定应用签名，开关可能看着是开的但对应的是旧签名。到「系统设置 → 隐私与安全性 → 辅助功能」，用「−」移除 Bowerbird，再用「+」加回来。

### 关掉了权限，应用还显示已授权。

macOS 不会通知运行中的应用。退出 Bowerbird 再打开。

### 需要屏幕录制或完全磁盘访问吗？

不需要。图片来自剪贴板，文件只存路径。

### 联网吗？

不联网。不上报、不检查更新、不同步。

### 数据在哪？

`~/Library/Application Support/Bowerbird/`：一个 SQLite 数据库加图片文件，未加密。设置在 `defaults` 的 `app.bowerbird.mac` 域。

### 怎么全部删掉？

「设置 → 历史 → 清除 → 全部记录」清掉历史；已固定的记录有自己的清除按钮，在下面一行。同一页的「退出时清除」会在每次退出时自动清掉，固定的保留。要一点不留，退出应用后执行：

```sh
rm -rf ~/Library/Application\ Support/Bowerbird
defaults delete app.bowerbird.mac
```

### 哪些内容不记录？

- 密码管理器标记为密码的内容。
- 从忽略列表里的应用复制的内容。默认有 1Password、Bitwarden 和钥匙串访问。
- 匹配忽略规则的文本。
- 暂停记录期间复制的任何内容。

### 历史保留多久？

文字和文件 30 天，图片 7 天，在「设置 → 历史」里改。固定的条目永久保留。

### 截图为什么搜不到？

macOS 默认把截图存成桌面上的文件，不经过剪贴板，Bowerbird 看不到。改用 ⌃⇧⌘4 截图，截图会直接复制到剪贴板；或者按 ⇧⌘5，在「选项」里把「存储到」改成「剪贴板」。

### 能收到 iPhone、iPad 上复制的内容吗？

文字和图片可以，在「设置 → 历史」里打开。文件不行。
