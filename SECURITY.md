# Security

Bowerbird stores what you copy, so a flaw here can expose private data. Please report it privately.

## Reporting

Email security reports to [terryxxchen@gmail.com](mailto:terryxxchen@gmail.com). Please don't open a public issue or post sensitive details in a discussion.

If **Security → Report a vulnerability** is available on this repository, you can use that private form instead. GitHub offers this feature for public repositories when the maintainers enable it; email also works while this repository is private.

Include the app version, the macOS version and the steps to reproduce. Leave real clipboard contents out of the report.

## What counts

- A way to read the history from outside the user's account.
- Something recorded that should not be: a password manager's copy, an ignored app, an ignore pattern that is skipped, a copy made while recording is paused.
- Any network connection made by the app.
- History that survives after it was cleared or its retention period ended.

## Supported versions

Only the latest release gets fixes.
